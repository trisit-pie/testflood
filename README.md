# แจ้งน้ำท่วม นนทบุรี

หน้าเว็บเดียว (`index.html`) สำหรับรับแจ้งและแสดงภาพรวมสถานการณ์น้ำท่วมในเขตเทศบาลนครนนทบุรี

## มีอะไรบ้าง
- **ภาพรวม**: จำนวนจุดที่ยังท่วม แผนผังจุดแจ้งเหตุ อันดับตำบลที่มีการแจ้งมากที่สุด และตารางซอย/ถนนพร้อมสถานะการสัญจรที่คำนวณจากระดับน้ำที่ผู้แจ้งรายงาน
- **แจ้งเหตุ**: ระบุชื่อและเบอร์โทรผู้แจ้ง เลือกประเภท (น้ำท่วม / น้ำลดแล้ว) ตำบล ซอย และความสูงของน้ำหรือสภาพหลังน้ำลด

## การตั้งค่า
แก้ค่าได้ที่ส่วน `configuration` ต้นสคริปต์ใน `index.html`:
- `TAMBONS` รายชื่อตำบล (ยังไม่ได้เทียบกับขอบเขตเทศบาลจริง ควรตรวจสอบ)
- `HEIGHTS` ปุ่มช่วงความสูงของน้ำ
- `STATUS` เกณฑ์สถานะการสัญจร (ค่าประมาณ ไม่ใช่ประกาศของหน่วยงาน)
- `WINDOW_MS` ช่วงเวลาที่นับรายงาน (ค่าเริ่มต้น 48 ชั่วโมง)

## ข้อจำกัดที่ควรรู้
- แผนผังเป็นภาพเชิงสัญลักษณ์ ตำแหน่งจุดเป็นค่าโดยประมาณภายในตำบล ไม่ใช่แผนที่จริง
- การเก็บรายงานร่วมกันใช้ระบบเก็บข้อมูลของ claude.ai ซึ่งทำงานเฉพาะเมื่อเปิดผ่านหน้าที่เผยแพร่ที่นั่น เมื่อเปิดไฟล์นี้จากที่อื่น รายงานจะถูกเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
- การให้ประชาชนแจ้งเองจริง ต้องต่อกับระบบหลังบ้านของหน่วยงาน (ฐานข้อมูลและบริการรับรายงาน) และต้องมีประกาศความเป็นส่วนตัวสำหรับชื่อและเบอร์โทร
- ยังไม่มีการยืนยันเบอร์ด้วยรหัส OTP
- ข้อมูลมาจากการแจ้งของประชาชนและยังไม่ผ่านการตรวจสอบโดยหน่วยงาน
